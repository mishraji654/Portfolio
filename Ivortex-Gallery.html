Vortex Gallery is an interactive 3D

Vortex Gallery is an interactive 3D image gallery that creates an immersive browsing experience using smooth camera movement, depth-based transitions, and WebGL rendering. The project combines creative visual storytelling with high-performance graphics to deliver a fluid, modern gallery experience.

Built by Rimjhim Mishra Type Interactive WebGL Experiment Stack HTML • CSS • JavaScript • Three.js • WebGL • GLSL Shaders

Project Overview

Vortex Gallery is a WebGL-powered interactive gallery that transforms a traditional image collection into a dynamic three-dimensional environment. Users can smoothly navigate through floating gallery walls while enjoying cinematic camera movements, realistic depth perception, and seamless transition effects. The project demonstrates how creative graphics programming can elevate modern web experiences.


Key Features

  • Immersive 3D image gallery with smooth camera navigation.
  • Interactive hover and focus animations for gallery items.
  • Depth-based transitions creating a realistic spatial experience.
  • GPU-accelerated rendering for high-performance visuals.
  • Responsive layout optimized for desktop and modern browsers.
  • Minimal UI to keep the focus entirely on the gallery content.

Technical Highlights

  • Built using Three.js for advanced 3D scene rendering.
  • WebGL rendering pipeline for smooth GPU-accelerated graphics.
  • Custom shaders and depth calculations for realistic visual effects.
  • JavaScript animation loop using requestAnimationFrame.
  • Optimized texture loading and rendering for better performance.
  • Modular architecture separating rendering, interaction, and animation logic.
